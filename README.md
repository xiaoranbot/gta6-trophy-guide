An offline guide and tracker for all 55 Grand Theft Auto VI PlayStation 5 trophies: official names, descriptions and grades, a roadmap to the platinum, a confirmed-missable warning (no mission replay — save at every chapter), and a checklist saved in the browser with export/import, kind filters and a spoiler-free mode. Pure static files; works with the network off.

## Run it

```sh
node serve.ts  # then open http://localhost:8080
```

Or open `app/index.html` from any static file server with `app/` at its root.
